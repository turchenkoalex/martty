Features

Everything Ghostty can draw, put to use.

Most terminal Markdown viewers stick to plain text. martty targets one terminal and uses all of it: kitty graphics with Unicode placeholders, OSC 8 hyperlinks, synchronized output and theme color queries.

Images inline

PNG, JPEG, GIF, WebP and SVG via the kitty graphics protocol. Animated GIF and WebP play.

Mermaid diagrams

Flowcharts, sequence, class, state, gantt, pie and more, rendered locally with no browser and colored by your theme.

Big headings

H1–H3 drawn large in JetBrains Mono, so a document has a shape you can scan.

LaTeX math

Inline $…$ sits on the text baseline; $$…$$ is centered. Typeset with TeX rules in STIX Two Math.

Theme-aware

Code, diagrams and headings take their colors from the terminal palette. Light or dark, it fits.

Built-in pager

Scrolling, smart-case search, link navigation, mouse wheel, zoom and pan for diagrams, live re-layout on resize.

Self-contained

One static binary. No browser, no Node, no runtime to install.

Clickable links

OSC 8 hyperlinks everywhere. In the pager, Tab through links and open .md files in place.

GitHub-flavored

Tables that wrap to fit, task lists, footnotes, alerts, front matter, emoji shortcodes and common inline HTML.

How it works

Pixels go once. Then it's all text.

Every image, diagram, formula and heading is transmitted to Ghostty a single time, then placed with Unicode placeholder characters. Each rendered line stays plain text.

Cheap scrolling. The pager redraws a window of text lines and never re-sends pixels, so panning a huge diagram is as fast as moving the cursor.

One probe. At startup martty asks the terminal one round of questions: theme colors, kitty graphics, cell size in pixels.

Graceful fallback. Without graphics, diagrams and formulas show as code and images as their alt text. Nothing panics.

Pager

Feels like less. Knows it's Markdown.

Long documents open in a full-screen pager. The mouse stays with Ghostty, so you can select text and Cmd-click links as usual.

Install

Download it, or build it from source.

Prebuilt binaries are for macOS on Apple silicon and Intel. Anywhere else, build with a recent stable Rust toolchain.

Download for macOS

$ mkdir -p ~/.local/bin
$ curl -fsSL https://github.com/turchenkoalex/martty/releases/latest/download/martty-aarch64-apple-darwin.tar.gz \
    | tar -xz -C ~/.local/bin --strip-components 1 martty-aarch64-apple-darwin/martty

On an Intel Mac use x86_64-apple-darwin. A file saved from the browser is quarantined; clear it with xattr -d com.apple.quarantine martty. Checksums and all files are on the release page.

Build and run

$ cargo install --git https://github.com/turchenkoalex/martty

$ martty README.md          # view a file
$ cat notes.md | martty     # read from stdin
$ martty -p short.md        # always open the pager
$ martty --width 72 doc.md  # lay out for 72 columns

Short output prints straight to stdout; anything taller than the screen opens the pager.
